Raptor Game Engine

A modular 2D engine for turn-based grid adventures, exploration, combat, and inclusive game design.

Minimal vertical slice

Move the player one orthogonal step at a time. Each valid move consumes one turn. Invalid moves are rejected without advancing the turn. The same events feed the board, status and a passive historical event log.
